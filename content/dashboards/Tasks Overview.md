# Tasks Overview

This mirrors your Obsidian Tasks dashboard. Special blocks are shown as code.

```md
## Overdue
```tasks
not done
hide backlink
show due
sort by due
(due before today)
```

## Due Today
```tasks
not done
hide backlink
show due
sort by path asc
(due on today)
```

## Due This Week
```tasks
not done
hide backlink
show due
sort by due
(due after today) AND (due before next sunday)
```

## No Due Date (Inbox)
```tasks
not done
no due date
hide backlink
sort by created reverse
```
```
